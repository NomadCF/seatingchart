# V6.7 Production Hardening and Teacher Workflow Expansion

This branch implements the next production-hardening and workflow expansion pass for Classroom Seating Planner.

Planned work includes:

- modular development source with deterministic single-file build output
- automated regression and build verification
- public JSON schemas and migration validation
- repository license, security, privacy, and data-handling documentation
- release packaging for portable HTML, hosted PWA, source archive, and checksums
- live valid-seat visualization and conflict-resolution actions
- seating-history and fairness analysis
- scheduled seating plans
- CSV export center and image export/copy workflow
- richer visual plan comparison
- near-duplicate roster suggestions and fast roster filters
- seat, zone, room, and plan annotations
- printable blank-room output
- import/export template packs
- WCAG 2.2 AA audit checks
- clearer collaboration change history

The final portable application remains a single self-contained HTML file. Hosted PWA companion files remain separate only for installation and offline support.
